# 程序 README 规范

> 新建固件程序/工程时在根目录创建 `README.md`，新建 `.c/.h` 源文件时在文件头添加
> readme 注释块。README 与文件头构成代码的"门面说明"，其版本信息必须与
> `version.h`、CHANGELOG 三方一致，防止"文档/注释与代码状态漂移"。

## 1、两层 README 与位置

| 层级 | 载体 | 位置 | 说明 |
|---|---|---|---|
| 程序/工程级 | `README.md` | 项目根目录 | 程序整体说明，与 `CHANGELOG.md`、协议文档并列 |
| 文件级 | 文件头注释块 | 每个新建 `.c/.h` 文件首部 | 本文件模块功能及归属固件版本的说明 |

- 新建程序/工程时必须创建 `README.md`；新建 `.c/.h` 源文件时必须带文件头注释块，禁止只交代码不带说明
- 修改已有程序/文件时，README 中相应描述同步更新

## 2、README.md 结构与模板（可直接粘贴）

```markdown
# <程序名称>

<一句话用途，如：温室环境采集终端（485 组网从机），定时采集上报土壤温湿度>

## 版本信息

| 版本号类型 | 当前值 | 备注 |
|---|---|---|
| FirmwareVersion 固件 | V1.0.0 | 与 version.h / CHANGELOG 一致 |
| HardwareVersion 硬件 | HW_V1.0 | 首版 PCB |
| ProtocolVersion 协议 | 1.0 | 平台接入协议 |
| ConfigVersion 配置 | 1 | 出厂配置结构 |

> 逐版本变更记录见 [CHANGELOG.md](CHANGELOG.md)

## 编译与烧录

<工具链 / 编译命令 / 烧录与升级方式>

## 通信与协议

- 协议文档：<路径>；ProtocolVersion 以上表为准
- 485 组网从机地址 / 波特率：<...>

## 目录结构

<主要目录/文件一句话说明>
```

- "当前值"一列在发版时随 CHANGELOG 正式条目同步更新，禁止只改 CHANGELOG 不改 README
- 版本号格式遵循 `versioning-spec.md`：固件 `V主.次.修订`、硬件 `HW_V主.次`、协议 `A.B`、配置为正整数

## 3、源文件头注释块模板（可直接粘贴）

```c
/**
 * @file        <文件名>.c
 * @brief       <模块功能：做什么、被谁调用>
 * @author      <作者>
 * @date        2026-09-07
 * @version     V1.0.0    // 对应固件版本，与 version.h / CHANGELOG 一致
 * @hardware    <HW_V1.0>  // 适配的硬件版本，main 等主程序文件必填，格式见 versioning-spec.md
 * @note        <约束/注意事项>
 *
 * 变更记录：
 * 2026-09-07 V1.0.0 <作者> 初始创建
 */
```

- 文件头中的版本号表示"该文件最后修改所对应的固件版本"，不单独演进文件级版本号，避免与固件版本号冲突
- `@hardware` 标注本文件适配的硬件版本（`HW_V主.次`）；`main.c` 等主程序文件必须标注（不标注则无法判断固件与哪版 PCB 配套），含硬件差异分支的驱动文件同样必填
- 文件改动（含新建）当天登记 CHANGELOG 顶部 "Unreleased" 区；发版时文件头版本号随正式条目同步更新
- `.h` 文件同样要求文件头注释块，`@brief` 侧重对外接口说明

## 4、新建程序文件的标准流程

1. 新建程序/工程 → 根目录创建 `README.md`（填写用途、四类版本号初始值）
2. 新建 `.c/.h` → 先写文件头注释块（功能、作者、日期、对应固件版本；`main.c` 等主程序附适配硬件版本），再写实现
3. 当天在 CHANGELOG 顶部 "Unreleased" 区登记改动
4. 发版时：`version.h`、README 版本信息表、CHANGELOG 正式条目三者版本号同步更新

## 5、校验清单（发版/评审用）

- [ ] README.md 存在，四类版本号与 `version.h` / CHANGELOG 最新条目一致
- [ ] 每个新 `.c/.h` 文件带文件头注释块，无"空文件无注释"
- [ ] 文件头版本号与 CHANGELOG 对应版本一致，无手写漂移
- [ ] `main.c` 等主程序文件头标注适配硬件版本，与 README 版本表中 HardwareVersion 一致
- [ ] README 中的编译/协议/配置说明与当前代码一致
