## A. 深色 kiosk / 板端工具风

适用于开发板测试台、机顶盒、车载、工控面板这类全屏深色界面（例：BoardLab，1280×800 全屏）。

```python

PANEL2 = "#1A2431"   # 卡片内嵌块 / 磁贴
NAV    = "#101821"   # 侧栏
LINE   = "#212C38"   # 描边、分隔线
TXT    = "#E9EFF6"   # 主文本
TXT2   = "#8A97A6"   # 次文本
TXT3   = "#5D6A79"   # 弱文本、标签
TEAL   = "#2DD4BF"   # 主强调（按钮、选中、进度）
BLUE   = "#38BDF8"
AMBER  = "#F5A524"
GREEN  = "#34D399"   # 运行中状态点
```

尺寸（1280×800 基准）：

| 部件 | 尺寸 |
|---|---|
| 顶栏 | 1280 × 64，底部 1px 边线 |
| 侧栏 | 208 宽，首项 y=46，步距 48，图标 16，文字 12.5 |
| 导航选中态 | 184 × 44 小组件，叠在侧栏实例上（左侧 3×20 强调条） |
| 内容区起始 | x=236，标题 23 Bold + 副标题 11.5 |
| KPI 卡 | 242 × 98，radius 14，间距 16；数值 26、单位 11.5、标签 10.5 |
| 主按钮 | h=34，radius 8；主按钮 teal 底 + `#06231F` 字 |
| 磁贴 | 168 × 56，radius 10 |

排版：标题 `Bold`、数字 `Medium` + MONO 字体、路径/内核串/版本号一律 MONO + TXT3。

## 右对齐 / 数值对齐

FigCraft 没有 auto-layout，文本靠左画。要右对齐时用 `rtext()`（基座内）：

```python
rtext("192.168.1.120", 1256, 26, 12.5, "#DCE6F0", "Medium", family=MONO)
```

它用 `est_width()`（CJK=1.0em、西文=0.52em、等宽=0.60em）估宽后反推 x。
多列右对齐时，同列取最长串的宽度作为列宽，再逐行右对齐，否则会参差。

## 顶栏右侧排布

从右向左累加，别从固定 x 开始写死：

```python
x = W - 24
for label, value in blocks:
    bw = max(est_width(value, 12.5, mono=True), est_width(label, 9.5)) + 2
    text(label, x - bw, 11, 9.5, TXT3, align="right", w=bw)
    text(value, x - bw, 26, 12.5, "#DCE6F0", "Medium", family=MONO, align="right", w=bw)
    x -= bw + 17
    rect(x, 18, 1, 26, "#243040")      # 分隔线
    x -= 18
```
