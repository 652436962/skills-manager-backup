## 使用方式

本 skill 为全局语言约束，无需显式调用，触发后自动生效。例如：

| 需求示例 | 自动处理 |
| -------- | -------- |
| "全程用中文回复我" | 对话全程使用简体中文，代码与专业术语保留原样 |
| "用英文写这段说明（仅术语）" | 正文仍用中文，不受输入外文影响 |

让 AI 在整个对话中主要使用简体中文回复，代码和专业英文术语保留原样，不受用户输入外文影响。
