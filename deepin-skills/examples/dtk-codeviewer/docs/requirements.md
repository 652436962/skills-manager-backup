## 1. 项目背景

dtk-codeviewer 是一个使用 `dtk-development` skill 指导开发的 DTK6 示例项目。项目选择代码和文本文件查看器作为业务载体，重点不是构建完整的代码编辑器，而是展示如何依据 skill 提供的 DTK 规范完成需求分析、控件选择、应用基础设施、主题视觉、配置管理、系统集成、工程组织和打包验证。

除多标签页、文件对话框、异步加载、水波进度提示、窗口模糊、主题图标及多种输入控件外，项目还覆盖 DTK 应用开发中的通用能力：

- `DApplication` 应用元数据、翻译加载、单实例和已有窗口重新激活。
- Qt logging category 与 `DLogManager` 分类日志。
- Qt Linguist 中文翻译和标准翻译安装目录。
- `DConfig` 用户配置、DCI 应用图标及 desktop 系统集成。
- CMake 源码与资源管理、安装规则和 Debian 打包。
- 大文件响应性、加载进度和安装内容等回归验证。

该项目是 `dtk-development` skill 的配套 Demo 和验证样例，不以生产级编辑器的完整功能为目标。

## 2. 目标用户

- deepin/UOS 桌面应用开发者
- DTK 控件和主题能力的学习者
- 使用 `dtk-development` skill 创建或维护 DTK 应用的开发者
- 需要参考 DTK 应用基础设施和工程组织方式的开发者
- 需要快速浏览文本或代码文件的用户

## 3. 功能需求

### 3.1 核心功能

| 编号 | 功能 | 描述 |
|------|------|------|
| F-01 | 文件打开 | 通过 DTabBar 添加按钮和 DFileDialog 选择文件 |
| F-02 | 多标签页 | DTabBar 管理多个已打开文件 |
| F-03 | 内容浏览 | DPlainTextEdit 以只读、等宽字体显示内容 |
| F-04 | 标签关闭 | 使用标签自身的关闭按钮关闭文件 |
| F-05 | 字体控制 | DSpinBox 在 10px～24px 范围内调节字号 |
| F-06 | 透明度控制 | DSlider 调节全窗口模糊遮罩透明度 |
| F-07 | 行号显示 | 仅绘制当前可见文本块的行号 |
| F-08 | 文件信息 | 底部显示文件路径、行数和大小 |
| F-09 | 大文件加载 | 文件读取和文本写入均采用事件循环分块处理 |
| F-10 | 加载反馈 | DWaterProgress 显示读取及内容写入进度 |
| F-11 | 操作提示 | DMessageManager 显示打开成功或失败信息 |
| F-12 | 状态保存 | DConfig 保存窗口尺寸、字号和透明度，配置不可用时使用内置默认值 |

| U-01 | 主窗口 | 使用 DMainWindow 和 DTitlebar |

| U-05 | 透明度输入 | 使用 DSlider，展示连续范围输入控件 |
| U-06 | 状态区域 | DLabel 显示文件信息和百分比 |
| U-07 | 主题适配 | 控件、模糊遮罩和图标跟随系统主题 |

## 4. 非功能需求

| 编号 | 需求 | 描述 |
|------|------|------|
| N-01 | 编译环境 | 支持 DTK6 + Qt6，CMake 3.13+ |
| N-02 | 运行平台 | deepin/UOS 桌面环境 |
| N-03 | 文件编码 | 使用 QStringDecoder 按 UTF-8 分块解码 |
| N-04 | 响应性 | 加载大文件期间事件循环和加载动画保持响应 |
| N-05 | 单实例 | 新进程退出，并通知已有实例恢复、显示和激活主窗口 |

## 5. 验收标准

1. 应用可正常编译、启动和退出。
2. 标签添加按钮可打开文件对话框，标签关闭按钮可关闭文件。
3. 字体使用 DSpinBox、透明度使用 DSlider，且调整后即时生效。
4. 标题栏、标签栏、编辑区和底部区域使用一致的模糊与透明度。
5. 加载期间显示 DWaterProgress，大文件加载不会长时间阻塞主线程。
6. 状态栏正确显示当前文件路径、行数和大小。
7. DConfig 元数据正确安装；元数据缺失时应用仍可使用默认值运行。
8. 再次启动应用时不创建第二个窗口，已有窗口从隐藏或最小化状态恢复并请求激活。
